# Скрипты для расчета энергетики радиолинии КА - АТ

## Основные файлы
1. runLinkAnalysis.m - Скрипт для запуска и визуализации
2. ChannelAnalyzer.m - Класс для расчета геометрии и энергетики

## Параметры
* Орбита: 800 км
* Частота: 12.5 ГГц
* Антенна КА: ФАР 32x32 элемента
* Углы места: от 90° до 27.5°

## Требования
MATLAB R2024a или новее.
